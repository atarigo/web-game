# Survival Loop 改用 OOXX 新美術風格：素材需求清單

本文件列出 `/game/survival-loop` 若改用 `/demo/ooxx` 新風格，還需要向 AI 畫師要求的素材類型。
所有新素材必須遵守 [ooxx-animation-plan.md](ooxx-animation-plan.md) 的畫布、錨點、幀數、命名規則。
本文件只列「類型與數量」，不涉及檔案格式（審稿用透明 PNG，定稿後統一轉 WebP atlas）。

## 現有新風格素材（demo 已有）

| 編號 | 素材         | 已有動作                | 已有方向 |
| ---- | ------------ | ----------------------- | -------- |
| 1    | 男主角（斧） | idle、walk、attack_1    | 僅 down  |
| 2    | 女主角（斧） | idle、walk、attack_1    | 僅 down  |
| 3    | 熊           | idle、walk、attack_claw | 僅 down  |
| 4    | 森林邊緣背景 | 六層側視差圖層          | 不適用   |

## 缺口總覽

### 一、主角補完（男、女各一套）

| 編號 | 需求                                    | 優先級 | 說明                                                                                       |
| ---- | --------------------------------------- | ------ | ------------------------------------------------------------------------------------------ |
| 1    | idle / walk / attack_1 的 left、up 方向 | 必要   | right 方向若角色左右對稱可由 left 鏡像，需先跟畫師確認武器持手是否對稱；不對稱則四方向都要 |
| 2    | hit、death 動作（四方向）               | 低     | 管線合約列為必要，但 survival-loop 玩法沒有主角受傷死亡，可延後                            |
| 3    | 搬運狀態（carry idle / carry walk）     | 選配   | 目前遊戲用頭上浮動圖示表示攜帶物，可先沿用程式做法                                         |
| 4    | 武器變體（矛或弓，用於打獵）            | 選配   | 首發可以用斧頭同一套動作打獵；變體依管線規則整套重繪                                       |

### 二、工人（全新角色類型）

現有遊戲有五種工人。新風格建議用「同一副身體換色換工具」壓低張數。

| 編號 | 工人       | 需要動作                         | 說明                                                                           |
| ---- | ---------- | -------------------------------- | ------------------------------------------------------------------------------ |
| 1    | 砍柴工     | idle、walk、attack_1（持斧）     | 可直接重用主角斧動作改配色                                                     |
| 2    | 獵人       | idle、walk、attack_1（持矛或弓） |                                                                                |
| 3    | 木材站工人 | idle、walk、work                 | work 是新動作類型，管線合約尚未定義，需先補合約（建議 4~6 幀，鋸木或搬料循環） |
| 4    | 肉品站工人 | idle、walk、work                 | work 動作為處理肉品循環                                                        |

工人主要固定站崗，方向可先只做 down，之後視需求補。

### 三、動物

| 編號 | 動物         | 需要動作                  | 說明                                                                         |
| ---- | ------------ | ------------------------- | ---------------------------------------------------------------------------- |
| 1    | 山豬（或鹿） | idle、walk、hit、death    | 全新素材，獵場主要獵物；會隨機走動所以至少要 down、left 兩方向（right 鏡像） |
| 2    | 熊           | 補 hit、death；補其餘方向 | demo 只有 down 的三種動作                                                    |

### 四、場景大圖（最關鍵的缺口）

demo 的森林邊緣背景是「橫向側視差」構圖（天空、遠景、中景、地面），
但 survival-loop 是**俯視自由移動加鏡頭跟隨**，這套背景無法直接使用。需要另外要求：

| 編號 | 需求                      | 說明                                                                                                                  |
| ---- | ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 1    | 俯視大地圖一張            | 對應現有玩法佈局：左上森林、右上獵場、左中木材站、右中肉品站、中下便當店；建議 2048 x 2048 起跳，同風格的雪地末日色調 |
| 2    | 或者改走俯視 tileset 路線 | 地表底圖加裝飾物件散布，彈性較高但管線要多做拼接規則，首發不建議                                                      |

### 五、建築與場景物件（單張靜態圖，不需逐幀動畫）

| 編號 | 物件   | 狀態數 | 說明                                 |
| ---- | ------ | ------ | ------------------------------------ |
| 1    | 樹     | 3      | 完整、受損、樹樁；倒下動畫選配       |
| 2    | 木材站 | 1      | 俯視或斜俯視角                       |
| 3    | 肉品站 | 1      | 同上                                 |
| 4    | 便當店 | 1      | 同上                                 |
| 5    | 木頭堆 | 1~3    | 收集區庫存視覺，可分空、半滿、滿三級 |
| 6    | 肉架   | 1~3    | 同上                                 |

目前掉落物是程式繪製的簡單圖形，改風格後建議換成小圖示，掉落物、頭上攜帶顯示、HUD 三處共用：

| 編號 | 圖示 |
| ---- | ---- |
| 1    | 木頭 |
| 2    | 生肉 |
| 3    | 便當 |
| 4    | 金幣 |

### 七、不需要向畫師要求的部分

| 編號 | 項目                                   | 理由                               |
| ---- | -------------------------------------- | ---------------------------------- |
| 1    | 雪花粒子、命中閃光、金幣閃光、升級特效 | 程式粒子與濾鏡即可，成本低且好調整 |
| 2    | 升級按鈕、雇用點標示等 UI              | 沿用網站既有 UI 風格               |

## 建議的委託順序

1. 俯視大地圖（決定整體風格能不能成立，先做）。
2. 主角補 left、up 方向。
3. 山豬整套。
4. 建築三棟與樹三態。
5. 物品小圖示四枚。
6. 工人（work 動作合約先補進 ooxx-animation-plan.md 再開工）。
7. 熊補完、主角 hit / death、各種選配。
