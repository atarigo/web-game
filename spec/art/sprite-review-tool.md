# 精靈圖審查工具（正規化 /demo/ooxx）

## 背景

`/demo/ooxx` 目前是 ooxx 素材專用的動畫檢視頁，實測很有用：素材進遊戲前先在這裡逐幀播放給人看。
本規格把它正規化成**通用驗收工具**，成為美術管線的固定關卡：

```
委託單 → AI 生成橫條圖 → 腳本切割 → 放入素材包資料夾 → /demo/sprites 審查 → 核可 → 轉 WebP 圖集 → 遊戲接入
```

沒有通過審查頁的素材，不准進任何遊戲。

## 路由與資料結構

```
/demo/sprites                 — 素材包列表（掃描已知包）
/demo/sprites?pack=<name>     — 檢視指定素材包
```

```
static/demo/sprites/<pack>/manifest.json   — 素材包清單檔
static/demo/sprites/<pack>/*.png           — 審查用單幀圖
```

清單檔沿用 ooxx 現有格式：畫布、錨點、基準線、動作、幀數、每幀時長、命中幀、靜態圖與背景項目。
現有 `/demo/ooxx` 內容遷移為第一個素材包，舊路由可導向新路由。

## 功能

### 既有功能（自 /demo/ooxx 保留）

1. 依清單檔列出素材與動作，逐幀瀏覽與自動播放（依每幀時長）。
2. 缺幀提示。
3. 背景分層檢視。

### 新增功能

| 編號 | 功能       | 目的                                                       |
| ---- | ---------- | ---------------------------------------------------------- |
| 1    | 輔助線覆蓋 | 顯示錨點十字、腳底基準線、畫布邊界，一眼看出幀間滑動與出界 |
| 2    | 鏡像預覽   | 一鍵水平翻轉播放，驗收「只畫一個方向、程式鏡像」的素材     |
| 3    | 播放速度   | 0.25 倍、0.5 倍、1 倍切換，慢速檢查漂移                    |
| 4    | 洋蔥皮     | 半透明疊上前一幀，檢查體型與位置一致性                     |
| 5    | 缺漏總表   | 對照清單檔一次列出整包缺少的檔案，不用逐格點               |
| 6    | 命中幀標記 | 播放到命中幀時閃現標記，驗收攻擊動作的節奏                 |
| 7    | 背景色切換 | 深、淺、格紋三種底色，檢查白邊與透明度殘影                 |

### 不做

1. 不做上傳與線上編輯：素材由檔案系統進出，工具只負責「看」。
2. 不做圖集打包：打包轉檔是獨立腳本的職責。

## 驗收流程約定

1. 開發方（Claude）把需求寫成自足委託單放 `spec/art/`，直接以 `codex exec --sandbox workspace-write` 背景派工給作圖方（Codex），一次一張單，不經使用者轉送。
2. 作圖方交付素材包與清單檔到審查包資料夾，依委託單標準自查後回報。
3. 開發方做檔案驗收：存在、路徑命名、尺寸、清單檔合法與合併正確；不評論圖片內容。
4. 使用者在審查頁看圖片效果，回覆「全過」或退件清單；退件由開發方帶清單重新派工，只重做退件項。
5. 效果驗收通過後，開發方把檔案複製進遊戲素材資料夾（`static/assets/<遊戲>/`）即定稿生效；轉 WebP 圖集為後續優化，審查包保留作對照原稿。
