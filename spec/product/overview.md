# 產品方向總覽

## 一句話定位

用同一套美術風格與自有角色，持續產出「上手快、玩起來爽、適合零碎時間」的網頁小遊戲，
以造型類小額付費賺取營收。未來不限定於 ad-game 這個站。

## 產品支柱

1. 十秒上手：不需要教學文字，看一眼就知道怎麼玩。
2. 單局短：三十秒到三分鐘一局，適合通勤、排隊、等人。
3. 舒壓與爽感優先：回饋要即時（音效、震動、特效、數字彈跳），失敗不懲罰。
4. 隨開隨玩：靜態部署、載入快、可離線（PWA 方向），不強制登入。
5. 同一個世界觀：所有遊戲共用美術風格與角色，角色是自有 IP，是品牌資產也是付費商品的載體。

## 為什麼要統一美術風格

1. 素材可跨遊戲重用：一套角色動畫（依 [../art/ooxx-animation-plan.md](../art/ooxx-animation-plan.md) 的合約）可以出現在多款遊戲，攤平生成與修圖成本。
2. 造型（皮膚）買一次、到處用：跨遊戲共用的造型比單一遊戲的造型更值得買，這是黏著與營收的交點。
3. 品牌識別：玩家看到畫面就知道是這個系列，利於口碑與分享。

## 遊戲選型準則

1. 玩法核心在「操作與回饋」而不是「內容量」：一套機制配少量素材就能成立。
2. 舒壓、爽、或收集整理的滿足感，三者至少佔一項。
3. 玩法機制可以參考市場上的類型（機制本身不受著作權保護），但美術、名稱、文案、關卡佈局都必須原創，詳見 [compliance.md](compliance.md)。
4. 單機優先，不做需要即時對戰伺服器的玩法（維運成本與範圍不符）。

## 發展階段（粗略路線）

1. 階段一（現在）：確立美術管線，survival-loop 換裝驗證新風格可行。
2. 階段二：補齊帳號雛形（先本機匿名紀錄，之後雲端同步）、每日挑戰等回訪機制。
3. 階段三：接金流，上架第一批造型，驗證付費意願。
4. 階段四：以同一套素材與帳號系統擴展到 ad-game 以外的新站或新遊戲系列。
