# 黏著力設計

短遊戲的黏著不能靠內容量堆，要靠三層結構：單局爽感、回訪誘因、長期收集。
以下依實作優先順序排列。

## 第一層：單局爽感（核心，沒有這層其他都白搭）

1. 即時回饋：每個操作都要有音效、粒子、數字彈跳或畫面震動；行動裝置加觸覺震動。
2. 連擊與節奏：連續成功要有升級中的回饋（音調升高、特效變大），製造心流。
3. 失敗不懲罰：失敗畫面要快、可立即重來（一鍵重開，不超過一秒）；不做體力或次數限制，那與舒壓定位相反。
4. 「差一點」設計：失敗時讓玩家看見自己離成功多近（例如差幾分、差幾格），驅動再來一次。

## 第二層：回訪誘因（讓人每天回來一下）

1. 每日挑戰：每天一組固定隨機種子的關卡或目標，全站玩家玩同一題，隔天更新。
2. 連續回訪紀錄：連續天數有小獎勵（給遊戲內貨幣或圖鑑進度），中斷不倒扣、不羞辱。
3. 每日一抽（免費）：登入送一次造型碎片或貨幣，養成開站習慣。
4. 通知要克制：PWA 通知只在使用者主動開啟時使用，寧可少也不要煩。

## 第三層：長期收集與跨遊戲進度（黏著的護城河）

1. 造型圖鑑：所有造型（含免費取得的）列成圖鑑，收集完成度本身就是目標；付費造型混在其中自然曝光。
2. 跨遊戲帳號等級：在任何一款遊戲玩都累積同一個帳號經驗，等級解鎖免費造型或稱號。
3. 共用貨幣：各遊戲產出的貨幣共通，鼓勵玩家嘗試新上架的遊戲。
4. 成就系統：每款遊戲少量成就，全站彙總。
5. 排行榜：每日與每週榜，週期性重置讓新玩家有機會上榜；先做本機與全站匿名榜即可。
6. 分享戰績：一鍵產生戰績圖卡（分數、造型、連續天數），分享即行銷。

## 賽季與活動（後期）

1. 限時主題活動：節慶換地圖配色與限定造型，製造回歸點。
2. 賽季通行證可以考慮，但必須輕量、便宜、獎勵全是造型，詳見 [monetization.md](monetization.md)。

## 技術前提

1. 帳號分兩步：先做本機匿名進度（現有紀錄機制延伸），之後加雲端同步（登入後合併本機進度）。
2. 進度資料結構要一開始就設計成跨遊戲共用（帳號層 / 遊戲層分離），避免之後搬遷。
3. 每日挑戰需要一個極輕的後端或以日期作種子的純前端方案；先用日期種子，零後端成本。

## 反面清單（明確不做）

1. 不做 pay-to-win：付費只能改變外觀，不能改變數值。
2. 不做體力、廣告牆、強制等待：與舒壓定位牴觸。
3. 不做賭博式轉蛋當作主要付費（法遵與體驗都差），詳見 [compliance.md](compliance.md)。
4. 不做無限彈窗求評分、求通知的騷擾式留存。
